# Data

This directory contains benchmark data used to evaluate defensive fragility:

- `validation/`: Independent tactical annotations and citations compiled from broadcast footage, open event data, and published tactical literature.
- `derived/`: Precomputed metric tables used to run the reproduction notebook without access to commercial tracking data.

Raw optical tracking data from PFF FC are not distributed here under the dataset terms. See [DATA_ACCESS.md](../DATA_ACCESS.md) for instructions on using licensed tracking files.
